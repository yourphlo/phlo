    Paste cells

    For a store whose sheet isn't in Google Drive (for example one opened from Outlook): open the day's tab, select the rows (Ctrl+A selects the whole tab), copy, and paste them into its box. Paste everything for this delivery, e.g. Saturday's and Sunday's tabs for a Monday. Build master then uses all the pasted rows for that store.
